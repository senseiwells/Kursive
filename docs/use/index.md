# Using Kursive

Kursive is a *fabric only* mod. Supporting both client and server sides.

It is actively maintained for only the latest version of the game.

<!--@include: ../../README.md#installing -->

## Downloading Scripts

Currently, there's no central repository for Kursive scripts so you'll need to either
write your own or download scripts from someone else.
